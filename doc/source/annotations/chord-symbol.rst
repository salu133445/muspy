============
Chord Symbol
============

The :class:`muspy.ChordSymbol` class is a container for chord markings (commonly found in jazz music).

=========== ================================= ==== =======
Attributes  Description                       Type Default
=========== ================================= ==== =======
root_str    Root pitch as a string            str
name        Chord type name                   str  'Maj'
text        Text                              str
is_system   Whether it is system-level        bool False
style       Style of the text (e.g. 'tempo')  str
