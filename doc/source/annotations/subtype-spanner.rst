===============
Subtype Spanner
===============

The :class:`muspy.SubtypeSpanner` class is a container for markings that span a certain duration and have a subtype.
The :class:`muspy.SubtypeSpanner` class is particularly useful as a parent class for more specific annotation types.

=========== ==================== ==== =======
Attributes  Description          Type Default
=========== ==================== ==== =======
duration    Duration             int
subtype     Subtype              str
