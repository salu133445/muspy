=============
Tempo Spanner
=============

The :class:`muspy.TempoSpanner` class is a container for tempo markings that indicate a *gradual*
change in tempo (e.g. *ritardando* and *accelerando*).

Attributes  Description          Type Default
=========== ==================== ==== =======
duration    Duration             int
