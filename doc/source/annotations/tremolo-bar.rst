===========
Tremolo Bar
===========

The :class:`muspy.TremoloBar` (not to be confused with :class:`muspy.Tremolo`) class is
a container for guitar tremolo bar markings.
The :class:`muspy.TremoloBar` class is a subclass of :class:`muspy.Bend`.

=========== ==================================== ============================= =======
Attributes  Description                          Type                          Default
=========== ==================================== ============================= =======
points      List of points that make up the bar  list of :class:`muspy.Point`
