===============
Hairpin Spanner
===============

The :class:`muspy.HairPinSpanner` class is a container for hairpin markings (e.g. *crescendo* and *decrescendo*).
The name for these markings stems from their close resemblance to actual hairpins.

============ ===================== ==== =======
Attributes   Description           Type Default
============ ===================== ==== =======
duration     Duration              int
subtype      Subtype               str
hairpin_type MusicXML hairpin type int  -1
