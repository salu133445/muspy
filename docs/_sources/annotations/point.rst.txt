=====
Point
=====

The :class:`muspy.Point` class is a container for the points that comprise :class:`muspy.Bend` objects.

=========== ==================================== ============ =======
Attributes  Description                          Type         Default
=========== ==================================== ============ =======
time        Start time                           int
pitch       Point pitch as a MIDI note number    int (0-127)
vibrato     Vibrato level of the point           int          0
=========== ==================================== ============ =======
